# phase2-asset-adoption Specification

## Purpose

量化模型层资产迁移：将上游比较法底座已完成的 S0/S1 成果按"仅本项目数据包派生"的边界迁入量化模型层，以可验证的三环指纹链固定数据宇宙，完成迁移进度对账，使量化模型层具备独立推进 S2 的条件。

## Requirements

### Requirement: 迁移完整性与三环指纹链

迁移完成时 SHALL 产出迁移清单与三环指纹链且全部核验通过：staged run 登记的源哈希与 S1 合同 run manifest 登记的源指纹一致（环2 = 环3）；本项目数据包 xlsx 实算哈希与该源指纹 SHALL 经登记链逐级追溯一致（环1 → 环2，追溯路径逐级记录、可核验），以证明迁移产物全部派生自本项目数据包。迁移清单 SHALL 逐项登记每个迁入资产的源路径、目标路径、来源层与哈希。任一环不一致且登记链无法追溯一致时，迁移流程 SHALL 停止并上报，不得修改哈希登记或数据以制造一致。

#### Scenario: 指纹链核验通过

- **WHEN** 计算三环指纹链并逐环核对
- **THEN** 环2 = 环3 直接相等；环1 经登记链（原始层与上游 staged run 的登记）追溯一致且追溯路径已登记；迁移清单完整登记各资产的两端路径、来源层与哈希

#### Scenario: 指纹不一致停止

- **WHEN** 任一环哈希比对不一致
- **THEN** 迁移停止并上报，不产生"已迁移完成"的记录，不出现对哈希登记或数据的改写

### Requirement: 数据宇宙边界

量化模型层 SHALL 固化《数据宇宙边界声明》：算法线（数据层、特征生成、模型训练与评估的一切输入）唯一数据源为用户自备数据包及其后续更新批次；禁入清单（底座历史湖数据、实体归一/别名表、其他平台/自采源）所列材料 SHALL NOT 作为算法输入。后续 change 的开发验证合同 SHALL 引用该边界声明（版本与哈希）。B1 对照属于评估用途的黑盒基线，不受禁入清单限制，但其输出 SHALL 仅作对照证据进入本项目。

#### Scenario: 边界声明可引用

- **WHEN** S2 起的 change 撰写开发验证合同
- **THEN** 合同的数据源条款引用边界声明的版本与哈希，内容与声明一致

#### Scenario: 禁入材料拦截

- **WHEN** 任何算法线产物被发现以禁入清单材料为直接输入
- **THEN** 检查或独立审核将其报告为违规，该产物不得作为有效证据

### Requirement: 源侧只读与副本一致

迁移过程对上游底座侧全部资产 SHALL 只读；每个迁入副本与其源的哈希 SHALL 一致。上游底座的后续演进不自动同步进本项目；本项目对引擎代码的后续修改 SHALL 在本仓库内走 change。

#### Scenario: 副本哈希一致

- **WHEN** 迁移完成后抽查任一迁入文件
- **THEN** 其哈希与迁移清单登记的上游源文件哈希一致

#### Scenario: 源侧零改动

- **WHEN** 迁移完成
- **THEN** 上游底座侧文件与迁移前一致（按迁移清单登记的源哈希核对）

### Requirement: 进度对账

README 当前状态 SHALL 反映迁移完成后的真实进度：S0/S1 已在上游底座完成并由本项目量化模型层接管（合同 run 以迁移清单登记值为 S2 起引用合同）、下一步为 S2（B0/B1/M1 三类基本对照）、底座复用方式已落定为"引擎代码全量副本（锚定上游底座登记提交）+ 用户自备数据派生数据资产、混源湖不迁、B1 黑盒对照"。

#### Scenario: README 与进度总账一致

- **WHEN** 阅读 README 当前状态与下一步
- **THEN** 与迁移清单及上游进度登记一致，不再存在"下一步起草工作包 A（S0–S2）"的过时表述

### Requirement: 既有规格逐字接管

上游底座已固化的 `phase2-data-contracts` 规格 SHALL 逐字收录为本规格面组成部分：收录副本与上游原文的条款正文（Purpose 与各 Requirement 及 Scenario）逐字一致，哈希登记入迁移清单；收录后该规格的行为变更 SHALL 走本仓库 change 的 delta。

#### Scenario: 收录副本逐字一致

- **WHEN** 比对本规格面的 phase2-data-contracts 收录副本与其上游定稿原文
- **THEN** 除 delta 格式所需的章节标题（如 ADDED Requirements）外，条款正文零差异

#### Scenario: 后续变更走本仓库

- **WHEN** S2 起需要修改数据合同行为
- **THEN** 以本仓库 change 的 MODIFIED delta 实施，不回写上游底座
